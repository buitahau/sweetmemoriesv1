# ADR

Architecture Decision Records: why key technical choices were made.

**Put here:** one file per real decision with trade-offs (data model, auth, storage, subdomain routing, script sandboxing).
**Not here:** open questions (`../decisions/`), feature specs (`../features/`), general design notes (`../architecture/`).

**File name:** `NNNN-short-title.md` (four-digit number, never reused).
**Sections:** Status (proposed/accepted/superseded), Context, Decision, Consequences.
Do not edit an accepted ADR. Supersede it with a new one.
