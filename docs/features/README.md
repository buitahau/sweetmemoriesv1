# Features

Feature specs, one per feature, plus `Progress.md` tracker.

**Put here:** `<feature-name>.md` with goal, status, side (backend, front-end or both), user flow, scope, user stories (ID, story, Given/When/Then scenarios; the source for the e2e tests), acceptance criteria. Keep `Progress.md` in sync with the status of each feature and its tasks.
**Not here:** implementation steps (`../tasks/`), open questions (`../decisions/`), mockups (`../ui/`).
