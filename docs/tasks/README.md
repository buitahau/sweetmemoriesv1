# Tasks

Implementation tasks with checklists, grouped by feature.

**Put here:** one folder per feature (`<feature-name>/`), one file per task (`NN-short-title.md`) with status (`todo`, `in progress`, `done`), side (backend or front-end), a checklist, a verification section (tests and checks that confirm it is done), a mockup link if any (to `../ui/`) and a link to the feature spec. Tick items as they are done.
**Not here:** feature requirements (`../features/`), open questions (`../decisions/`).
